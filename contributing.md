# Contributing

Thanks for considering a contribution. The bar is high to keep the list small and useful.

## Acceptable contributions

- New CS1010-specific resources we don't already cover.
- Better one-line descriptions for existing entries.
- Corrections (broken links, outdated info, factual errors).
- New categories (open an issue first to discuss).

## Quality bar

Each entry must be:

1. **Specific to CS1010 / CS1010S / CS1010E / CS1010J / CS1010X**, or significantly better than what's already in the General section.
2. **Free or with a meaningful free version**. Free trials don't count.
3. **Still active and maintained**. Don't add dead repos or abandoned blogs.
4. **Described in one line** explaining what it's for and when to use it.

## How to submit

1. Fork this repository.
2. Add your entry alphabetically (or where it makes sense in the section's existing order).
3. Open a pull request with a short explanation:
   - What is this resource?
   - Why does it belong in the list?
   - Do you have any conflict of interest?

## What gets rejected

- Self-promotion without disclosure or a track record.
- Generic Python tutorials we already link to.
- Affiliate links without disclosure.
- Entries that don't add unique value over what's already listed.
