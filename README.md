## Understanding the variants

NUS offers CS1010 in several variants depending on your faculty. The variant you take affects the language and the assessment structure. Pick yours before reading further.

| Variant | Language | Audience | Notes |
|---|---|---|---|
| [CS1010](https://nusmods.com/courses/CS1010/programming-methodology) | C | General introductory | The original C-based variant. Run from `nus-cs1010.github.io` per semester. |
| [CS1010S](https://nusmods.com/courses/CS1010S/programming-methodology) | Python | Faculty of Science (and others) | Largest variant. Uses Coursemology platform. Most online resources target this. |
| [CS1010E](https://nusmods.com/courses/CS1010E/programming-methodology) | Python (IDLE) | Engineering students | Same language as CS1010S, different assessment structure (one practical assessment + lab exercises rather than Coursemology). |
| [CS1010J](https://nusmods.com/courses/CS1010J/programming-methodology) | Java | Java-based programmes | Java instead of Python or C. Different content focus. |
| [CS1010X](https://nusmods.com/courses/CS1010X/programming-methodology) | Python | Returning NSmen | Equivalent content to other CS1010 variants. Taken pre-school-term to ease back into academic life. |

If you're not sure which one you're in, check NUSMods or your faculty's recommended pre-requisites.

## Official course information

- **[NUSMods](https://nusmods.com)** — Module timetabling and student-written reviews. Always read recent reviews before the semester starts.
- **[NUS Module Catalogue (via NUSMods)](https://nusmods.com/modules)** — Search any NUS module by code. Official descriptions and pre-requisites.
- **[CS1010 (C variant) official course site](https://nus-cs1010.github.io/)** — The C variant's authoritative site, per-semester (e.g. `/2425-s1/`). Lecture notes, exercises, exam information, code style guide.
- **[CS1010S course page](https://www.comp.nus.edu.sg/~nityalak/CS1010S/)** — Public CS1010S course page. Coursemology platform guide, lecture material indices, problem-solving notes.
- **NUS Canvas** — Authoritative source for your specific semester's syllabus, lecture recordings, and assignments. Bookmark the module page once you have access.

## General Python learning

- **[Official Python Tutorial](https://docs.python.org/3/tutorial/)** — Free, accurate, and well-written. Most students skip this and shouldn't.
- **[Real Python](https://realpython.com)** — Mix of free and paid tutorials. Free ones are high quality. Search by topic rather than browsing.
- **[Python Basics on freeCodeCamp](https://www.freecodecamp.org/learn/scientific-computing-with-python/)** — Free certificate-track if you want structure outside the module.
- **[CS50P: Introduction to Programming with Python](https://cs50.harvard.edu/python/)** — Harvard's free Python course. More rigorous than most. Useful supplement.

## Practice platforms

- **[CS1010 (C variant) weekly exercises](https://nus-cs1010.github.io/)** — Browse the current semester's site (e.g. `2425-s1`, `2425-s2`) for weekly programming exercises. About 90 questions across 11 weekly sets, with ~25 graded. The rest are practice.
- **[Coursemology](https://coursemology.org/)** — The platform CS1010S uses for missions, training, tutorials, side quests. Login required; your CS1010S course will appear once enrolled.
- **[LeetCode (Easy tier)](https://leetcode.com/problemset/all/?difficulty=EASY)** — Wider than CS1010 needs, but the Easy tier covers similar territory. Filter by tag (arrays, strings, basic recursion) to stay relevant.
- **[CodingBat (Python)](https://codingbat.com/python)** — Small focused exercises, no signup needed. Good for warm-up.
- **[Exercism Python track](https://exercism.org/tracks/python)** — Free, with optional human mentorship. Slower than LeetCode but builds depth.

## Books worth reading

- **[Automate the Boring Stuff with Python](https://automatetheboringstuff.com)** — Al Sweigart. Free to read online. Singapore-relevant because the projects (web scraping, file processing) overlap heavily with FYP work later.
- **[Think Python](https://greenteapress.com/wp/think-python-3rd-edition/)** — Allen Downey. Free. Closer to CS1010S level than most pop-CS books.
- **[Composing Programs](https://www.composingprograms.com)** — Free online textbook adapted from Berkeley's CS61A. Beyond CS1010 scope but excellent if you want a deeper foundation.

## Tools and IDEs

- **[VS Code](https://code.visualstudio.com)** — Most CS1010 students end up here. Install the Python extension and the Pylance extension.
- **[Python Tutor visualiser](https://pythontutor.com)** — Step through code line by line and watch memory change. Best tool for understanding recursion and loops if you're stuck.
- **[Replit](https://replit.com)** — Browser-based Python for when you don't want to install anything locally. Free tier is enough for CS1010 scope.
- **[Jupyter Notebooks](https://jupyter.org)** — Required for some CS1010S labs. Install via Anaconda for the easiest path.
