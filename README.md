## Understanding the variants

NUS offers CS1010 in several variants depending on your faculty. The variant you take affects the language and the assessment structure.

- [CS1010](https://nusmods.com/courses/CS1010/programming-methodology) - C language; the original variant; for general introductory students.
- [CS1010S](https://nusmods.com/courses/CS1010S/programming-methodology) - Python via Coursemology; Faculty of Science; the largest variant.
- [CS1010E](https://nusmods.com/courses/CS1010E/programming-methodology) - Python via IDLE; engineering students; different assessment structure from CS1010S.
- [CS1010J](https://nusmods.com/courses/CS1010J/programming-methodology) - Java; for Java-based programmes.
- [CS1010X](https://nusmods.com/courses/CS1010X/programming-methodology) - Python; for returning NSmen; taken pre-school-term to ease back into academic life.

If you are not sure which one you are in, check NUSMods or your faculty pre-requisites.

## General Python learning

- [Official Python Tutorial](https://docs.python.org/3/tutorial/) - Free, accurate, and well-written.
- [Real Python](https://realpython.com) - Mix of free and paid tutorials; the free ones are high quality.
- [Python Basics on freeCodeCamp](https://www.freecodecamp.org/learn/scientific-computing-with-python/) - Free certificate-track for structure outside the module.
- [CS50P: Introduction to Programming with Python](https://cs50.harvard.edu/python/) - Harvard free Python course; rigorous and a useful supplement.

## Practice platforms

- [Coursemology](https://coursemology.org) - The platform CS1010S uses for missions, training, tutorials, and side quests.
- [LeetCode (Easy tier)](https://leetcode.com/problemset/all/?difficulty=EASY) - Wider than CS1010 needs, but the Easy tier covers similar territory.
- [CodingBat (Python)](https://codingbat.com/python) - Small focused exercises with no signup needed.
- [Exercism Python track](https://exercism.org/tracks/python) - Free track with optional human mentorship.

## Books

- [Automate the Boring Stuff with Python](https://automatetheboringstuff.com) - Al Sweigart; free to read online; projects overlap with FYP work later.
- [Think Python](https://greenteapress.com/wp/think-python-3rd-edition/) - Allen Downey; free; closer to CS1010S level than most pop-CS books.
- [Composing Programs](https://www.composingprograms.com) - Free online textbook adapted from Berkeley CS61A; beyond CS1010 scope but excellent for foundation.

## Tools and IDEs

- [VS Code](https://code.visualstudio.com) - Where most CS1010 students end up; install the Python and Pylance extensions.
- [Python Tutor visualiser](https://pythontutor.com) - Step through code line by line and watch memory change.
- [Replit](https://replit.com) - Browser-based Python when you do not want to install locally.
- [Jupyter Notebooks](https://jupyter.org) - Required for some CS1010S labs; install via Anaconda for the easiest path.
