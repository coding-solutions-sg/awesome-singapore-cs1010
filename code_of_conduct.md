# Code of Conduct

This list is for sharing useful resources. Be helpful, be brief, be honest.

## Expected behaviour

- Suggest resources that genuinely help CS1010 students learn.
- Disclose conflicts (e.g. "I work for X" if recommending X).
- Respect the quality bar in `README.md` even when it means your PR is closed.

## Unacceptable behaviour

- Cold marketing of tutor services without a verifiable track record.
- Adding affiliate links without disclosure.
- Personal attacks, harassment, discriminatory language.

## Enforcement

The maintainers may close PRs and remove entries that violate this code. Repeated violations result in being blocked from the repository.

Report issues by opening a GitHub issue or emailing coding.solutions.incs@gmail.com.
